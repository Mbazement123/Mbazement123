### ⚙️ Example Voting App — DevOps

A distributed voting application and DevOps capstone. The Python vote service sends votes through Redis, a .NET worker stores them in PostgreSQL, and a Node.js result service displays totals. The project includes Docker Compose, Kubernetes/Helm, Terraform for EKS, and a GitHub Actions CI/CD workflow.

[View project →](https://github.com/Mbazement123/example-voting-app) · [Architecture](https://github.com/Mbazement123/example-voting-app/blob/main/architecture.excalidraw.png)

**Tech:** Docker · Kubernetes · Helm · Terraform · AWS EKS · GitHub Actions · Redis · PostgreSQL
